# Contribuir a Pujazo

Gracias por tu interés.

## Flujo

1. Trabaja sobre la rama `develop` (o una feature branch desde `develop`).
2. Mantén el MVP sin IA externa, auth, pagos, scraping ni secretos.
3. Escribe o actualiza pruebas cuando toques el motor en `src/lib/analysis`.
4. Ejecuta `pnpm lint`, `pnpm typecheck`, `pnpm test` y `pnpm build` antes de abrir PR.
5. Usa mensajes de commit claros y en español o inglés consistente con el historial.

## Alcance

Prioriza claridad para usuarios de fantasy en España, accesibilidad básica y un motor determinista comprensible.
